## **План тестирования мобильного приложения "Мобильный хоспис"**

### **Объект тестирования**
Мобильное приложение "Мобильный хоспис".

### **Процесс тестирования**
1. Ручное тестирование приложения.
2. Составление чек-листа для проверки приложения.
3. Описание тест-кейсов для проверки приложения.
4. Автоматизация тест-кейсов по чек-листу.
5. Формирование отчётов о тестировании.

### **Виды тестирования**
- Исследовательское тестирование - в связи с отсутствием ТЗ его необходимо провести в первую очередь для понимания логики работы приложения;
- Функциональное тестирование;
- Тестирование пользовательского интерфейса (UI Testing);
- Тестирование удобства использования (Usability Testing);
- Тестирование безопасности.

### **Описание приложения**
- Приложение даёт функционал по работе с новостями хосписа и включает в себя:
    * информацию о новостях и функционал для работы с ними;
    * тематические цитаты;
    * информацию о приложении.

### **Границы приложения, тестируемые функциональности**
#### Authorization - страница авторизации
- Поле ввода логина.
- Поле ввода пароля.

#### Меню приложения (бургер-меню)
- **Main** - главная страница.
- **News** - страница раздела новостей.
- **About** - страница раздела с данными о приложении.

#### Main - главная страница
- Кнопка для сворачивания/разворачивания списка опубликованных новостей.
- Кнопка **ALL NEWS** - переход на страницу раздела News.
- Плашки опубликованных новостей - разворачивание/сворачивание контента по нажатию.

#### News - страница раздела новостей
- Плашки опубликованных новостей - разворачивание/сворачивание контента по нажатию.
- Кнопка сортировки списка опубликованных новостей.
- Кнопка фильтрации списка опубликованных новостей - переход на страницу настройки фильтра Filter news.
- Кнопка перехода на страницу управления всеми новостями Control panel.

#### Filter news - страница фильтрации новостей (при переходе со страницы раздела News)
- Поле выбора категории с дропдауном.
- Поле указания начальной даты периода - датапикер.
- Поле указания конечной даты периода - датапикер.
- Кнопка **FILTER** для применения фильтра и перехода на страницу News с отфильтрованным списком опубликованных новостей.
- Кнопка **CANCEL** для отмены применения фильтра и перехода на страницу News с ранее отображаемым списком опубликованных новостей.

#### Control panel - страница управления всеми новостями
- Кнопка сортировки списка всех новостей.
- Кнопка фильтрации списка всех новостей - переход на страницу настройки фильтра Filter news.
- Кнопка создания новости - переход на страницу создания новости Creating News.
- Плашки всех новостей:
    * Разворачивание/сворачивание контента по нажатию.
    * Кнопка редактирования новости - переход на страницу редактирования новости Editing News.
    * Кнопка удаления новости - открывает диалоговое окно подтверждения удаления с кнопками CANCEL И OK:
        * Кнопка **CANCEL** для отмены удаления.
        * Кнопка **OK** для подтверждения удаления.

#### Filter news - страница фильтрации новостей (при переходе со страницы Control panel)
- Поле выбора категории с дропдауном.
- Поле указания начальной даты периода - датапикер.
- Поле указания конечной даты периода - датапикер.
- Чек-бокс Active - по умолчанию активирован.
- Чек-бокс Not active - по умолчанию активирован.
- Кнопка **FILTER** для применения фильтра и перехода на страницу News с отфильтрованным списком всех новостей.
- Кнопка **CANCEL** для отмены применения фильтра и перехода на страницу News с ранее отображаемым списком всех новостей.

#### Creating News - страница создания новости
- Поле выбора категории с дропдауном.
- Поле ввода заголовка.
- Поле указания даты публикации - датапикер.
- Поле указания времени публикации - таймпикер.
- Поле ввода описания.
- Тогл указания статуса.

- Кнопка **CANCEL** для отмены создания новости и выхода со страницы - открывает диалоговое окно подтверждения выхода с кнопками CANCEL И OK:
    * Кнопка **CANCEL** для отмены выхода и продолжения взаимодействия со страницей создания новости.
    * Кнопка **OK** для подтверждения выхода, закрытия страницы создания новости и возврата на страницу Control panel.

#### Editing News - страница редактирования новости

- Поле указания даты публикации - датапикер - предзаполнено значением из новости.
- Поле указания времени публикации - таймпикер - предзаполнено значением из новости.
- Поле ввода описания - предзаполнено значением из новости.
- Тогл указания статуса - предзаполнено значением из новости.
- Кнопка **SAVE** для сохранения изменений в новости.
- Кнопка **CANCEL** для отмены редактирования новости и выхода со страницы - открывает диалоговое окно подтверждения выхода с кнопками CANCEL И OK:
    * Кнопка **CANCEL** для отмены выхода и продолжения взаимодействия со страницей редактирования новости.
    * Кнопка **OK** для подтверждения выхода, закрытия страницы редактирования новости и возврата на страницу Control panel.

#### About - страница раздела с данными о приложении
- Подблок "Privacy Policy" со ссылкой на страницу с политикой конфиденциальности.
- Подблок "Terms of use" со ссылкой на страницу с пользовательским соглашением.
- Кнопка приложения "Назад" (стрелка) - переход обратно на предыдущую страницу.

#### Love is all (Иконка бабочки) - страница с цитатами

#### Профиль (Иконка человека)

### 6. Перечень используемых инструментов тестирования
- **Android Studio** - официальная интегрированная среда разработки основана на IntelliJ IDEA для создания приложений на платформе Android.
- **Эмулятор Android API 29** - соответствует Android 10 (Q).
- **Espresso** - фреймворк для автоматизированного тестирования пользовательского интерфейса мобильных приложений на платформе Android.
- **Java JDK 11** — версия языка программирования Java, для тестировщиков полезна обширной экосистемой библиотек и фреймворков, которые облегчают процесс тестирования.
- **JUnit 4** — тестовый фреймворк для Java, предназначенный для упрощения процесса тестирования программного обеспечения.
- **Record Espresso Test** - инструмент, который автоматически записывает действия пользователя для создания тестов.
- **Layout Inspector** - мощный инструмент, который позволяет визуально просматривать и анализировать структуру пользовательского интерфейса приложения.
- **GitHub** - веб-сервис, предоставляющий хостинг для проектов, использующих Git.
- **Allure** – гибкий инструмент для составления отчетов о тестировании.

### 8. Перечень и описание возможных рисков при автоматизации тестирования

- **Отсутствие технического задания (ТЗ)**
    * Нет четкого понимания ожидаемого результата.
    * Возможна некорректная расстановка приоритетов для каких-то функциональных блоков/сценариев.

- **Отсутствие доступа к базе данных**
    * Невозможно автономно, не прибегая к сторонней помощи коллег, протестировать работу приложения на стороне БД.
    * Баги на стороне БД могут остаться незамеченными.

- **Частые изменения и масштабирование приложения**
    * Необходимость актуализировать тесты после каждого изменения.
    * Увеличение количества тестов и рост сложности управления ими.
